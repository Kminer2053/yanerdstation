# 서울역 여행 게임 자산 출처·빌드 기록

작성일: 2026-11-06

이 문서는 3번 구현에서 추가한 여행자·역무원·휴대 소품과 구운란사이 그림 자산을 다룬다. 기존 서울역 건축 형상·현장 파사드 사진의 출처 기록을 대체하지 않는다.

## 제작 방식과 참고 자료

여행자 6종과 역무원, 캐리어, 철도블럭, 구운란사이 소품은 이번 작업에서 작성한 Three.js 도형·재질·애니메이션 코드로 만든 게임 자산이다. 상품 포장·캔·획득 카드 그림은 직접 작성한 SVG를 Sharp로 PNG로 변환했다. Codex가 코드 작성을 도왔으며, 그림 파일 생성을 위한 imagegen 도구·구독형 이미지 생성 서비스·이미지 생성 API 출력은 사용하지 않았다.

구운란사이는 2024-07-18 보도된 [「코레일유통, 추억의 기차여행 간식 '구운란사이' 출시」](https://www.sidae.com/article/2024071812551662000)의 회사 제공 상품사진과 상품 설명을 참고했다. 기사 사진의 출처 표기는 코레일유통이며, 기사에서 확인한 구성은 **구운계란 2개와 칠성사이다 190mL 1개**다. 투명 사각 포장, 베이지색 종이 라벨, 갈색·황토색 상품명, Storyway 표기와 녹색·흰색 캔의 외관을 게임에서 알아볼 수 있도록 재구성했다.

[코레일유통 공식 PB상품 소개](https://www.korailretail.com/content.do?menuNo=2010600)는 스토리웨이 전용 PB 사업의 맥락을 확인하는 보조 자료로 사용했다. 해당 일반 소개 페이지를 구운란사이의 현재 매장별 판매 여부나 현재 포장 규격의 증거로 사용하지 않았다.

참고한 보도사진 원본은 배포 자산에 넣지 않았다. 게임은 기사 사진을 다운로드하거나 그대로 텍스처로 읽지 않고, 저장소에서 새로 작성한 SVG와 그 PNG 산출물을 사용한다. 2026-11-06 현재 판매 가격은 검증하지 않아 게임 자산에 가격을 표시하지 않았다.

## 자산 목록

파일 경로는 저장소 루트 기준이다.

| 자산 | 소스·구현 | 게임에서의 용도 |
| --- | --- | --- |
| 여행자 6종 | `src/commons-avatar-styles.js`, `src/commons-avatars.js` | 어린이 남·여, 성인 남·여, 어르신 남·여의 키·체형·머리·옷·얼굴 구분 |
| 역무원 2명 | 같은 아바타 렌더러의 `npcRole: 'staff'` | 안내센터·선상통로 안내부스의 감색 제복·모자·배지 |
| 캐리어·가방 | `src/commons-avatars.js` | 손잡이·바퀴가 있는 휴대 소품과 보행 동작 |

캐릭터는 외부 인물 모델·인물 사진을 가져오지 않고 기본 도형을 조합했다. 역무원 외형은 역할을 구분하기 위한 게임용 디자인이다. 철도블럭도 특정 실물 키트의 차종·부품 수·조립 형상을 정밀 재현한 모델로 취급하지 않는다.

## PNG 재생성과 산출물

재생성 스크립트는 `tools/build-commons-product.mjs`다. 이미 설치된 Sharp를 사용해 세 SVG를 지정 폭으로 래스터화하고 PNG 압축 수준 9로 저장한다.

```sh
node tools/build-commons-product.mjs
```

작성 시점의 PNG를 읽어 확인한 기록은 다음과 같다. 이번 문서 작성에서는 이 명령을 다시 실행하거나 자산을 변경하지 않았다.

| PNG | 크기 | 파일 크기 | SHA-256 |
| --- | --- | ---: | --- |
| `guunran-sai-package.png` | 512 × 448 | 155,249 bytes | `360589b6ed72cfed048e4ad8ad23434351a47cd5a122587350c201d351a95e78` |
| `guunran-sai-can.png` | 256 × 256 | 14,944 bytes | `54f88792be859b7b3bd8334905b1cef14a3c9a3cfb366f517c7ee4d292b4bb81` |
| `guunran-sai-item.png` | 640 × 520 | 76,244 bytes | `bfaa71d4f35c0e94a2c9f4e52b2fef936b84f37900817a012d996fca106e8997` |

확인 환경은 Node.js v26.13.0, Sharp 0.35.4, libvips 8.18.6이다. SVG의 글꼴 목록은 Apple SD Gothic Neo, Noto Sans KR, Arial 등의 시스템 글꼴을 사용한다. 다른 환경에서 다시 생성하면 글꼴 대체와 래스터라이저 차이로 모양·파일 해시가 달라질 수 있으므로 한글 표시와 라벨 방향을 다시 눈으로 확인해야 한다. 이 재생성 명령은 현재 `npm run build`와 별도이며, 게임 빌드는 저장된 PNG를 정적 자산으로 포함한다.

## 표현 범위와 확인 기록

캐릭터·소품의 비율과 단순화한 포장 형상은 화면에서 구분하기 위한 디자인 값이다. 현장 실측이나 실물 치수 측정을 수행하지 않았고, 제조사·브랜드가 제공하거나 검수한 공식 3D 모델이 아니다. 라벨의 작은 글자·인증 표기·소비기한을 포함한 실물 표시 전체의 정확성을 검증한 자료로 사용하지 않는다. 2024년 공개사진을 참고한 외관이며 현재 포장·재고·판매 상태가 같다는 의미도 아니다.

실제 브라우저에서 여섯 캐릭터와 제복 역무원, 캐리어, 철도블럭, 구운란사이의 두 계란·캔·포장 그림을 확인했다. 포장과 캔의 글자가 앞에서 거꾸로 보이지 않는 방향도 재확인했다. 아바타는 최대 32명 범위에서 부위별 인스턴스 배치를 사용한다.

게임의 인증샷·네컷 사진은 위 상품 카드 이미지를 합성해 캐릭터 사진처럼 만드는 방식이 아니다. `src/commons-photo.js`가 실제 3D 장면을 포즈별로 렌더링한 직후 Canvas로 복사하고, UI의 `src/commons-photo-studio.js`가 그 촬영 결과를 사진으로 구성한다. 외부 카메라 기기 권한은 사용하지 않는다. 실제 3층 인생네컷 배경에서 네 장의 포즈·썸네일·합성 미리보기까지 확인했다.

`tools/test-commons-avatars.mjs`에서는 6종 구분, 역무원 제복, 휴대 소품 구성, 32명 한도, 유효한 애니메이션 행렬, 인쇄면 방향, 네 번의 실제 렌더·복사 호출, 촬영 후 상태 복원과 자원 해제를 검사했다. 관련 기존 공간·카메라 검사와 Vite 빌드도 통과했다. 이 기록은 자산 제작·로컬 검증 기록이며 운영 배포나 브랜드의 공식 승인을 뜻하지 않는다.
