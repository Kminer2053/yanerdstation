# 보류: 서울역 메타버스·여행게임 개선

> **이하 최초 기록 당시의 상태:** 사용자 요구와 첨부 관찰을 원문 이력으로 보존한다. 아래의 “기록만”, “후속 구현”, “아직 구현하거나 시험하지 않았다”는 최초 기록 시점의 상태이며 현재 상태를 뜻하지 않는다. 현재는 2026-11-07 전체 구현 승인에 따라 진행 중이다. 이후 구현·배포와 로컬·운영 검증 범위는 [구현 진행 기록](pending-work-implementation-2026-11-07.md) 및 [v79 운영 검증 기록](commons-production-v79-verification-2026-11-07.md)을 기준으로 확인한다. 확인 전 항목까지 완료한 것으로 해석하지 않는다.

2026-11-07 사용자 요청과 첨부 5장을 기준으로 정리했다. **내용 파악·보류 기록·전체 목록 보고만 수행하며, 구현·화면 변경·운영 데이터 변경·배포는 하지 않는다.**

## 네 컷 미니앱 상세 요구

- 서울의 주요 명소를 **배경 또는 프레임**으로 사용한다. 특정 명소 목록과 디자인은 아직 정하지 않았다.
- **내 캐릭터로 촬영하는 방식**과 **셀카에서 인물만 누끼를 따 합성하는 방식**을 선택할 수 있도록 한다. 인물 분리·합성은 아직 구현하거나 시험하지 않았다.
- 선택한 캐릭터 또는 인물과 서울 명소 배경·프레임으로 네 컷을 구성해, 실제 네 컷 사진을 찍는 경험으로 이어지게 한다.
- 특정 카메라 입력 방식·외부 서비스·모델·처리 위치는 이번 요청에서 확정하지 않는다. 기존 부스 앞 4장 캡처만으로 이 요구를 충족했다고 판단하지 않는다.

## 첨부 근거와 범위

첨부 1~5는 위 `evidence/pending-game-20261107/`에 사용자 제공 원본 바이트로 보존했다. 첨부에서 보이는 현상과 사용자의 요청을 기록한 것이며, 실제 이동 동작이나 메시지의 원인까지 재현·진단했다고 표현하지 않는다. 현재 보류한 항목의 구현 우선순위는 이번에 새로 확정하지 않았다.
