# 사진 현재화·전국 편집·서울역 여행게임 구현·검증 포트폴리오

사용자 요청의 진행 순서는 사진 작업(1) → 전국 편집기(2) → 서울역 다중접속 게임(3)이다. 격리 브랜치에서 구현·로컬 검증을 마친 뒤 2026-11-06 사용자 승인으로 **편집기 v15·서비스 v78 운영 배포와 실제 MCP 계정 연결을 완료했다.** [최종 배포 기록](deployment-2026-11-06.md)을 참고한다. 아래 단계별 검증에는 배포 전 시점의 이력이 포함돼 있다.

2026-11-07 후속 요청으로 **스크린샷 PNG 첨부 오류만 편집기 v16에 수정·배포했다.** 실제 사용자 PNG와 첨부 API·보안 회귀를 확인했으며, 배포 상태는 `succeeded`다. [PNG 업로드 수정 기록](png-upload-fix-2026-11-07.md)에 소스·검증·배포를 연결했다. [화면 통합·연결 관리·지도 캡처 요구](pending-codex-connection-2026-11-06.md)는 계속 기록 전용 보류 상태다.

후속 요구 전체는 [통합 보류 목록](pending-work-2026-11-07.md)에 연결했다. 편집기 6개 묶음과 [서울역 여행게임 9개 항목·사용자 첨부 5장](pending-seoul-travel-game-2026-11-07.md)을 포함하며, 이 요구 기록을 구현 완료나 새 배포로 표현하지 않는다.

## 3번 구현 범위와 최종 검증

기존 경량 공간을 여행 미션이 있는 서울역 체험으로 확장했다. 어린이·성인·어르신 남녀 6종의 여행자와 캐리어를 고르고, 안내센터 또는 선상통로 안내부스의 역무원에게 말을 걸어 여행을 시작한다. 두 역무원은 모의 산책자 표시를 꺼도 남아 있고, 방문자의 도착점과 별도 보행 셀에서 서서 안내한다.

여권에는 안내받기, TRAIN MATES의 철도블럭, 한정선 인증샷, 선상통로 계단 인증샷, 스토리웨이의 구운란사이, 3층 인생네컷의 6개 스탬프가 있다. 미션 목록의 찾아가기는 등록된 유효 보행점으로 이동할 뿐 보상을 주지 않는다. 해당 장소에서 말 걸기·받기·촬영을 해야 진행된다. 획득한 두 소품은 가방에서 장착·해제할 수 있으며 매장 밖에서도 계속 들고 다닌다. 구운란사이는 실제 PB 상품의 구운란 2개·칠성사이다 190mL 구성을 참고한 게임 일러스트와 3D 소품이다. 현재 판매가·실제 결제·재고·현물 지급은 연결하지 않는다.

두 인증샷은 철도블럭을 손에 든 상태에서 찍는다. 인생네컷은 실제 3D 화면을 인사·만세·고개 인사·기본 자세로 네 번 렌더링하여 촬영한다. 각 프레임은 원본 종횡비를 보존한 한 장의 PNG로 합성하며, 화면 검토·다시 찍기·저장·지원 브라우저의 파일 공유를 제공한다. 외부 카메라·마이크·GPS 권한을 사용하지 않고 촬영 이미지를 서버에 업로드하지 않는다.

혼자서도 같은 미션 규칙으로 모든 이벤트를 수행할 수 있다. 공유방에서는 서버가 확인한 개인 인벤토리·스탬프만 적용하고, 상대에게는 캐릭터와 현재 손에 든 소품만 기존 위치·자세와 함께 전달한다. 솔로 여권과 공유방 여권은 분리한다. 혼자 저장한 소지품을 공유방 서버에 가져와 보상으로 인정받는 경로는 없다. 기존 키보드·조이스틱 이동, 조망·시설 목록, 층 전환과 실제 계단 이동 경로를 유지한다.

### 한계와 최종 인계

- 공유방은 기존의 최대 20명·20분과 주기적 동기화를 사용한다. 대규모 상시접속·계정 간 영속 인벤토리·자유 채팅을 구현한 것으로 표현하지 않는다. 솔로 여권은 해당 브라우저 탭의 세션 저장소에 보관하며, 공유방 입장·퇴장 시 별도 상태로 전환한다.
- 서버의 사진 검증은 장수·장소·층·접근 가능성·소지품 조건을 확인한다. 이미지 내용을 판독하거나 실제 현장 방문을 인증하지 않는다. 네 컷은 화면 속 3D 여행 사진이며 외부 카메라 사진이 아니다.
- 게임 건축·사진·보행점은 기존 COMMONS 기준본의 재구성이다. 현재 현장과 모든 최신 운영 상태가 같다는 보장이 아니며, 기존 구조물과 가까운 카메라에서는 벽 클리핑이 나타날 수 있다. 장소 이동 후 시점 회전으로 확인한 결과와 카메라의 모든 각도에서 가시성을 보장하는 것은 구분한다.
- 실제 상품 구성을 참고한 일러스트와 소품은 게임 표현이다. [구운란사이 출시 보도](https://www.sidae.com/article/2024071812551662000)를 참고한 구성으로 현재 판매 여부·가격·실제 상품 지급을 확인한 것은 아니다.
- 모바일 확인은 Chrome의 390×844 화면 에뮬레이션에서 선택·캐릭터 변경·여권·가방·시점 회전을 조작한 범위다. 실제 휴대폰, 터치만으로 전체 미션 수행, 기기별 프레임·메모리 성능은 확인하지 않았다.
- 실제 공유방의 6개 이벤트, 원격 소품 표시와 매장 밖 유지, 두 인증샷, 네 컷 PNG 실파일 검증을 마쳤다. 대표 증거 8개를 이 문서의 `evidence/`에 원본 바이트 그대로 복사했다. 검증용 메모리 서버와 게임 시험 탭은 종료했다. 운영 배포는 수행하지 않았다.
